# Lumière — Hotel Concierge RAG Chatbot

Premium hotel concierge chatbot built with Flask, FAISS, MiniLM embeddings, and OpenRouter LLM.

## Project Structure

```
hotel-rag/
├── app.py                         # Flask entry point
├── ingest.py                      # Vectorstore builder (run once)
├── requirements.txt
├── .env.example
├── backend/
│   ├── core/
│   │   ├── retriever.py           # FAISS retrieval (cached)
│   │   └── llm.py                 # OpenRouter LLM call
│   └── routes/
│       └── chat.py                # /api/chat, /api/reset
├── frontend/
│   ├── templates/index.html
│   └── static/
│       ├── css/style.css
│       └── js/main.js
├── data/pdfs/                     # Drop your hotel PDFs here
└── vectorstore/                   # Auto-generated by ingest.py
```

## Setup

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Configure environment
```bash
cp .env.example .env
# Edit .env and set your OPENROUTER_API_KEY and SECRET_KEY
```

### 3. Add your data
- Drop hotel PDF files into `data/pdfs/`
- Edit `ingest.py` if you want a different website scraped

### 4. Build vectorstore (skip if you already have one)
```bash
python ingest.py
```
> Copy your existing `vectorstore/` folder into the project root if you already have it.

## Run

```bash
python app.py
```

Open `http://localhost:5000`

## Notes

- The embedding model and FAISS index are loaded once and cached in memory — no repeated disk reads.
- Conversation history is maintained server-side in Flask sessions (last 10 turns).
- Sources are shown below every answer in a collapsible pill UI.
- Dark/light theme persists in localStorage.
